How to Install

1
Download the plugin file
Click the download button above. Save the aissociate-manifest.xml file somewhere you can find it.
2
Open Word and go to Add-ins
In Word, click Insert tab in the ribbon, then click Get Add-ins (or Office Add-ins).
3
Upload the plugin
Click My Add-ins tab, then Upload My Add-in. Browse to the downloaded aissociate-manifest.xml file and click Upload.
4
Start using AI:ssociate
The AI:ssociate group appears in your Home tab. Click Open Panel to launch the chat sidebar. Highlight text and ask away!
